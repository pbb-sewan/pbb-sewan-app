Catatan dusun

Backup dan restore (Admin Utama)

Backup memuat data wajib pajak, pembayaran, catatan, register setoran, waktu pencatatan, dan informasi perangkat. File foto tidak ikut tersalin; yang disimpan hanya alamat file fotonya.

Restore menggabungkan atau memperbarui data yang cocok berdasarkan NOP dan tahun. Data yang tidak ada di file backup tidak dihapus. Fitur ini hanya tersedia untuk Admin Utama.
